# Perfil do Usuário — Login com FirebaseUI (Android / Kotlin)

Aplicativo Android com autenticação de usuários usando **Firebase Authentication** e a biblioteca **FirebaseUI Auth**, seguindo o modelo da documentação oficial.

## Autores
- Victor Hugo Soares Matos Brandão
- Thales de Melo Fontes

## Funcionalidades
- **Login** com FirebaseUI (e-mail e senha)
- **Cadastro de usuários** em tela própria (nome, e-mail, senha e confirmação de senha), com validação dos campos
- **Tela principal** que mostra o nome e o e-mail do usuário logado
- **Botão Sair**, que encerra a sessão e volta para a tela de login

## Tecnologias
- Kotlin
- Android Studio (JDK 17)
- Firebase Authentication
- FirebaseUI Auth 9.0.0
- Material Design 3 e ViewBinding
